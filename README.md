# 🍵 Dünyanın En Yavaş Çay Molası Hesaplayıcısı

**Bu proje, insanlığın en büyük sorununu çözmek için yaratılmıştır: Kaç çay molası almalıyım?**

Ama dikkat! Bu hesaplayıcı öyle yavaş çalışır ki çayınız soğur, işiniz biter, belki emekli olursunuz. Tamamen absürt, eğlenceli ve gereksiz bir yazılımdır. Gerçekten çalışır. Gerçekten yavaştır.

## Neden Bu Proje?

Çünkü normal hesaplayıcılar çok hızlı. Çay molası hız işi değildir. Çay molası bir yaşam tarzıdır. Bir felsefedir. Bir çay felsefesidir.

Bu kod:
- Aşırı yavaş döngüler kullanır.
- Rastgele "bir çay daha koyayım" der.
- Sonunda size abartılı sayıda mola önerir.
- Çayın soğuduğunu hatırlatır.

## Nasıl Kullanılır?

```bash
python cay_molasi.py
```

Sonra kaç saat çalışacağınızı girin. Sabırlı olun. Çok sabırlı olun. Belki bir çay demleyin beklerken... ama kod bitmeden soğur.

## Özellikler

- 🐢 Yavaşlık garantisi (gerçek time.sleep var)
- 🍵 Türkçe absürt mesajlar
- 📈 Abartılı mola önerileri
- 🤔 Felsefi çay notları
- 😅 Hiçbir işe yaramaz ama eğlencelidir
